Programming Works

Closest to the Pin

Link: GitHub

This basic 3D game is made using a custom engine which implements physics simulation, 3D sound, basic AI for NPCs, and even basic multiplayer functionality via UDP. The player is tasked with hitting a golf ball as close to the hole as possible. Your final distance is added together (meaning a lower score is better) and compared to all other players. The player with the lowest score wins.

RPG Works

The Elder Scrolls Adventures

Link: GDrive

A homebrew sourcebook for running 5.5 Edition Dungeons & Dragons campaigns set in The Elder Scrolls setting. I made it with a "lightweight" design philsophy; rely on established D&D rules and only add/change what the ruleset does not accomodate. Includes new player races, birthsigns (implemented as backgrounds), magic items and artifacts from the games, and a new system for enchanting your own equipment.

The Oblivion Crisis

Link: GDrive

A custom campaign designed to be run using the above TES Adventures homebrew module. Functions as a remake of TES4: Oblivion, but with numerous aspects modified for better storytelling, better attention to detail, and to better facilitate multiple player characters being present.
